# Registrar Document Request Tracker

IT 415 - Application Development and Emerging Technologies (Midterm Exam)
Scenario 4: Registrar Document Request Tracker

## Description

A browser-based app that digitizes document requests at the Registrar's window.
Students can send a request and check its status using a reference number.
Registrar staff can view, search, filter, process, and claim requests, and see summaries.

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)
- localStorage (no database, no server)

## Project Structure

- `index.html` - main page
- `css/style.css` - styling
- `js/app.js` - main application logic
- `js/storage.js` - localStorage reading and writing
- `js/utils.js` - helper functions (dates, reference numbers)
- `docs/` - requirements analysis, AI prompt log, screenshots

## How to Run

Open `index.html` in a web browser (or use the VS Code Live Server extension).
